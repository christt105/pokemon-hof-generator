# Pokémon Hall of Fame Generator

A web app that generates Hall of Fame images in the style of each Pokémon generation. Pick your trainer, your Pokémon party, and get a faithful recreation of the Hall of Fame screen — downloadable as PNG or video.

Built with Godot 4, exported to HTML5 and hosted on GitHub Pages.

## What it does

- Select a generation (Gen 1–5)
- Enter your trainer name and choose a trainer sprite
- Fill in up to 6 Pokémon with nickname, level and gender
- The app renders the Hall of Fame sequence with the original layout and aesthetic
- Download the final frame as PNG or the full animation as WebM

## Tech

- Godot 4 (GDScript)
- PokeAPI for Pokémon sprites
- GitHub Pages for hosting
